# Release Evidence Contract

A production candidate is eligible only when one record contains:

1. accepted spec and ADR references;
2. exact source commit and clean-worktree confirmation;
3. required CI/content/build/security checks;
4. Graphify health/output revision and scoped GitNexus impact summary;
5. private Sites version and browser/mobile/Lighthouse evidence;
6. explicit maintainer approval;
7. deployed Sites version, canonical domain, HTTPS/header/content smoke results;
8. prior stable Sites version and DNS/security-policy backup as rollback targets;
9. remaining risks and next action.

The project journal entry is append-only. Corrections add a dated follow-up.
