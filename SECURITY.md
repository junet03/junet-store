# Security policy

Please do not report vulnerabilities through a public issue. Use GitHub's private
security-advisory flow for this repository after it is published, or contact the
maintainer privately through an already established trusted channel.

Include the affected URL/commit, reproduction steps, impact, and any temporary
mitigation. Do not include real credentials, private source, personal data, or
attack traffic in a public report. V1 has no accounts, forms, upload, database,
analytics, or public application API.

MQL5 CodeGraph reports belong to that project's
[private advisory page](https://github.com/junet03/mql5-codegraph/security/advisories/new).
